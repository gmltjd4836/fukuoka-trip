# 희성 ♥ 소민의 후쿠오카 여행 · 업데이트 v3

**날짜:** 2026년 11월 24일 ~ 11월 29일 (5박 6일)

## 가장 중요한 것: 기존 데이터 유지

- 변경할 파일: `index.html`, `app.js`, `styles.css` 세 개. GitHub 저장소의 루트에 기존 이름 그대로 덮어쓰세요.
- **`config.js`는 수정하거나 삭제하지 마세요.** 기존 개인용/공유 연결 설정을 유지해야 합니다.
- 업로드하기 전에 기존 사이트의 톱니바퀴 → **백업 파일 저장**을 눌러 JSON 백업을 다운로드하세요.
- 이 업데이트는 기존 `fukuoka-trip-v2-data` 저장 키와 JSON 백업 양식을 그대로 사용합니다.
- 숙소·항공편·예약·경비·준비물 데이터는 그대로 유지합니다. 경비/준비물은 화면에서만 숨깁니다.
- 기존 장소·일정의 중복은 앱에서 자동 정리됩니다. 같은 장소는 이름과 가까운 좌표 또는 동일한 OSM ID로 판단하며, 같은 날짜/같은 장소 방문은 한 번만 표시합니다. 메모가 있으면 유지하고 가장 이른 방문시간을 씁니다.
- 기존 로컬 데이터가 처음 정리될 때 수정 전 스냅샷이 브라우저의 `fukuoka-trip-v3-original-snapshot` 키에 한 번 보관됩니다. 그래도 **별도 JSON 다운로드 백업이 더 안전**합니다.
- 예전 사이트와 다른 주소·기기·브라우저에서는 개인용 데이터가 자동으로 따라오지 않습니다. 필요하면 JSON을 가져와 복원하세요.

## 바뀐 기능

- 희성 ♥ 소민 커플 테마의 첫 화면과 여행 약속 카드
- 한국 시간으로 자동 계산되는 D-DAY, 여행 중에는 1~6일차, 여행 종료 후 안내
- 장소 저장 및 검색결과 분류에서 사용자 검색어(예: 라멘) 때문에 모든 결과가 라멘으로 분류되던 문제 해결
- 하카타역 등 역·교통 유형, 라멘·모츠나베·야키니쿠 등 음식 종류 자동 분류와 수동 선택
- 같은 장소 중복 저장 및 같은 날짜 중복 일정 추가 차단, 기존 중복 표시 정리
- 일정의 장소명 옆에 종류 배지 표시
- 준비 탭: 숙소·항공·예약을 상세 카드로 표시. 예약번호, 주소, 일정, 객실·인원, 예약 사이트·연락처·메모 등을 한 번에 표시
- 경비 및 준비물은 보이지 않을 뿐 데이터는 백업에 포함

## 주의

- 무료 OpenStreetMap 검색은 서비스 사정과 검색어에 따라 결과가 달라집니다. 종류 분류는 장소명과 장소 유형에 기반한 추정이므로 필요한 경우 ‘수정’에서 바꿀 수 있습니다.
- 한국 시간 자정에 자동으로 디데이를 다시 계산하며, 컴퓨터와 휴대폰의 시계가 정상적이어야 합니다.
- 비공개 예약번호 등을 GitHub 코드 파일에 직접 쓰지 마세요. 앱에 기록하세요. 개인용 저장은 해당 브라우저에만 저장되니 주기적으로 백업하세요.

## GitHub 업데이트 방법

1. 기존 여행 사이트에서 **⚙ 설정 → 백업 파일 저장**.
2. GitHub 저장소 `fukuoka-trip`에서 `Add file` → `Upload files`.
3. 여기 담긴 `index.html`, `styles.css`, `app.js` **3개를 업로드**해 같은 이름 파일을 덮어쓰기.
4. `Commit changes` 후 GitHub Pages에 반영될 때까지 기다리고 새로고침.
5. 기존 일정·숙소·예약이 보이는지 확인. 안 보이면 화면에서 더 입력하지 말고 백업을 확인하세요.

기존 `config.js` 설정은 그대로 유지됩니다. Supabase 공유방을 쓰고 있다면 같은 방에 연결되어 있어야 기존 데이터가 보입니다.
